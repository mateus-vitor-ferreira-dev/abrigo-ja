| `api-rest.md` | Recursos, verbos, status, versionamento e HATEOAS | 15% |
| `gateway.md` | Gateway e regras de roteamento | 10% |
| `bff.md` | Dois BFFs e a diferença entre as respostas | 10% |
| `dados.md` | Database per service, consistência eventual, dual write, outbox | 15% |
| `saga.md` | Variante, modelagem, compensações, cenário de falha | 20% |

decisões justificadas frente à alternativa descartada.
