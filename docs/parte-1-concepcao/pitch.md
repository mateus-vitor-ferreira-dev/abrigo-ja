# Roteiro do pitch — 5 minutos

Os 5 minutos são **do grupo**, não por pessoa. Os quatro se revezam dentro do tempo, e todos
devem falar: integrante presente que não toma a palavra perde 50% da nota da etapa.

| Tempo | Integrante | Conteúdo |
|---|---|---|
| 0:00–1:15 | | Problema e por que ele importa |
| 1:15–2:30 | | Dados e referências |
| 2:30–3:45 | | Impacto social e como medir |
| 3:45–5:00 | | Esboço da solução |

## Arguição

A pergunta é dirigida **nominalmente** — o docente escolhe quem responde. Todos precisam saber
responder sobre qualquer parte, não apenas sobre a própria fala.
