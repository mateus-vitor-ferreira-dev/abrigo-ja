# Parte 1 — Concepção e pitch (10%)

Apresentação em 17/09/2026. Pitch de 5 minutos para o grupo inteiro — **os quatro falam**.

| Arquivo | Entregável | Peso |
|---|---|---|
| `pitch.md` | Roteiro do pitch, com divisão de fala | 20% (qualidade do pitch) |
| `problema.md` | Problema e motivação | 25% |
| `referencias.md` | Mínimo de **4 referências** de base | 25% |
| `impacto-social.md` | Quem é beneficiado, como, e como medir | 20% |
| `identidade/` | Nome, logo (opcional) | — |

Repositório configurado corretamente vale os 10% restantes: público, README inicial e os
**4 integrantes como contribuidores** — nome ausente da lista de contribuidores custa −50% da
nota do integrante.
